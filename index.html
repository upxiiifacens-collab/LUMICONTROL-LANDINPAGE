Contexto

A falta de soluções para a diminuição do desperdício de energia, em muitas regiões é um problema que vem cresendo cada dia mais, em muitas regiões do país.

Luzes permanecem acessas durante o dia, mesmo com a presença de iluminação natural suficiente para claream ambiente. Essas práticas aumentam os gastos financeiros e também agravam os impactos ambientais, a solução busca incentivar a conscientização em relação ao consumo de energia elétrica.

Segundo pesquisas realizadas pelo STF(Supremo Tribunal Federal) a substituição por Lampadas de LED ofecere uma economia de energia em até 80% sobre as Florescentes, Imaginando isso pensamos em uma maneira de reduzir ainda mais essa porcentagem para 90% de ecomonia.

Após realizar testes um engenheiro eletrico concluiu que o projeto apresenta práticidade e facilidade.

Exemplo de dor

Segundo pesquisas realizada por nossa equipe levantamos dados, pessoas relataram uma baixa produtividade gerando perda de tempo com a falta de um sistema automatizado.

Proposta

O projeto Lumicontrol exclarece o potencia da automação integrada á eficiência energética em comércios residenciais. O projeto conta com um sistema que possibilita o controle da iluminação com base no ambiente.

O sistema recebe as informaçãoes do usuario e as aplica na dashbord, gerando relatorios, graficos e dicas de como otimizar o consumo de energia em cada área.

Como a solução funciona

O protótipo funcional (WEB) de automação inteligente focado na iluminação, o sistema recebe os dados atraves do usuario o sistema processa os dados no Frontend computando para o Beckend assim enviando os dados para armazenar via Banco de dados(SQL) após isso o sistema possibilita visualização na Interface Web, possibilitando a vizualização de gtaficos e relatorios e dicas.
